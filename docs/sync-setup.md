# Google Drive 동기화 설정

Nopsidian 은 **본인의 Google Cloud 프로젝트**로 Drive 에 접근합니다(앱 자체 서버·계정 없음, ADR-0001).
권한은 `drive.file` 하나뿐이라 앱이 만든 파일만 보이고, 기존 Drive 파일에는 접근하지 못합니다.
계정 이메일은 **지금 확인**이 Drive의 `about.user`에서 읽을 수 있을 때만 마스킹해 표시하며, 별도 이메일 권한을 요청하지 않습니다.

## 1. Google Cloud 설정 (한 번만)
1. <https://console.cloud.google.com/> 에서 새 프로젝트를 만든다.
2. **API 및 서비스 → 라이브러리** 에서 *Google Drive API* 를 사용 설정한다.
3. **API 및 서비스 → OAuth 동의 화면**: 사용자 유형 *외부*, 앱 이름 아무거나, 지원 이메일 본인.
   - 범위(scope)에 `…/auth/drive.file` 을 추가한다(민감하지 않은 범위라 앱 검증이 필요 없다).
   - **게시 상태를 "프로덕션"으로 바꾼다.** "테스트" 상태에서는 refresh token 이 7일 뒤 만료돼 계속 다시 로그인해야 한다.
     (검증되지 않은 앱 경고가 한 번 뜨지만, 본인 계정이면 *고급 → 계속* 으로 진행하면 된다.)
4. **사용자 인증 정보 → 사용자 인증 정보 만들기 → OAuth 클라이언트 ID**, 애플리케이션 유형 **데스크톱 앱**.
5. 만들어진 *클라이언트 ID* (그리고 있으면 *클라이언트 보안 비밀*) 를 복사한다.

## 2. 앱에서 연결
1. 사이드바의 "☁ 동기화" → 클라이언트 ID(와 비밀) 입력 → 저장. 값은 OS 키체인으로 암호화되어 이 기기에만 저장된다.
2. "Google 계정 연결" → 브라우저에서 로그인·허용 → "연결됐어요" 가 뜨면 닫는다.
3. "이 볼트를 Drive 와 동기화" 를 켜고 **첫 동기화 미리보기**에서 계획(올림/내려받음/병합/삭제)을 확인한 뒤 실행한다.
   이후에는 파일이 바뀐 뒤 10초, 그리고 2분마다 자동으로 동기화한다.

## 3. 두 번째 기기
같은 클라이언트 ID 로 연결하고, **같은 이름의 빈 폴더**를 볼트로 연다(Drive 폴더는 볼트 이름으로 매칭된다: `Nopsidian/<볼트 이름>/`).
첫 동기화 미리보기에서 "내려받기"가 나열되면 맞게 연결된 것이다.

## 문제 해결
설정 창의 **4. 진단**에서 토큰 만료, 마지막 동기화, 실패 사유, Drive 폴더 상태를 한 번에 볼 수 있습니다.
**지금 확인**은 토큰과 `Nopsidian/<볼트 이름>/` 폴더만 읽고, 동기화·업로드·삭제는 하지 않습니다.

| 화면의 오류 | 확인할 것 |
|---|---|
| Google 로그인이 만료됐어요 (`HTTP 401`) | **지금 확인**은 먼저 refresh token으로 갱신을 시도합니다. 잠시 뒤 다시 확인하고, 동기화가 계속 401이면 Google 계정을 다시 연결합니다. |
| Drive API가 꺼져 있어요 (`accessNotConfigured`) | Google Cloud 콘솔 → API 및 서비스 → 라이브러리에서 **Google Drive API**를 사용 설정합니다. |
| 저장 공간이 부족해요 (`storageQuotaExceeded`) | Google Drive 저장 공간을 비우거나 다른 계정을 씁니다. |
| 요청이 제한됐어요 (`rateLimitExceeded`, `dailyLimitExceeded`) | 1~5분 뒤 **지금 확인**을 다시 누릅니다. |
| 인터넷에 연결되지 않았어요 (`NETWORK`) | 네트워크를 확인한 뒤 다시 시도합니다. |
| Drive 접근 권한이 없어요 (`HTTP 403`) | Google 계정 권한과 클라이언트 설정을 확인합니다. |
| Google 쪽 일시 오류예요 (`HTTP 5xx`) | 잠시 뒤 다시 시도합니다. |
| Drive에서 파일이나 폴더를 찾을 수 없어요 (`HTTP 404`) | 다시 확인하거나 동기화를 다시 실행합니다. |
| Drive 폴더를 찾을 수 없어요 (`FOLDER_MISSING`) | 두 번째 기기라면 같은 이름의 볼트를 열었는지 확인합니다. 첫 동기화 전에는 폴더가 없는 것이 정상입니다. |

**진단 정보 복사**는 클라이언트 ID 끝 4자리, 보안 비밀 등록 여부, 계정 연결 여부, 폴더 존재 여부, 오류 코드만 복사합니다.
토큰·비밀 값·이메일(마스킹 포함)·폴더 ID/경로·노트 이름/경로는 복사하지 않습니다.

## 동작 요약
- 한쪽만 바뀌면 그쪽을 따른다. 양쪽이 다른 블록을 고치면 자동 병합, 같은 블록을 고치면 양쪽 내용을 모두 남기고 충돌로 표시한다.
- 삭제는 상대 쪽 휴지통(로컬 `.nopsidian/trash/`, Drive 휴지통)으로 간다. 한 번에 파일의 20%를 넘게 지우려 하면 멈추고 묻는다.
- 이름 변경·이동은 다시 올리지 않고 Drive 에서도 이동으로 처리한다.
- 동기화 제외: `.nopsidian/` 아래의 인덱스·기록·휴지통·동기화 상태(단 `config.json`, `graph.json`, `comments/` 는 포함), `.git/`, 임시 파일.
- Drive 웹에서 파일을 고쳐도 반영된다(내용 해시를 다시 계산한다).
