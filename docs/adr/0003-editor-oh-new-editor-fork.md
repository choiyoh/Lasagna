# ADR-0003: 에디터는 oh-new-editor를 포크해 사용한다

- 상태: 승인
- 날짜: 2026-10-12
- 대체: 설계 문서 5.2의 "BlockNote로 시작 → TipTap/ProseMirror로 하강"

## 맥락
2단계 에디터를 고르기 위해 BlockNote 0.55, TipTap 3.31, 그리고 사용자의 `choiyoh/oh-new-editor`(ProseMirror 기반, MIT)를
Electron 안에서 스파이크로 비교했다(콜아웃 > 목록 > 토글 > 열 > 콜아웃 중첩, 속성 보존, 렌더링, 명령).

| 항목 | BlockNote | TipTap | oh-new-editor |
|---|---|---|---|
| 중첩 콜아웃·토글 | 통과 | 통과 | 통과 |
| 열 레이아웃 | 막힘 (공식 패키지는 GPL-3.0 OR 상용) | 통과 | 통과 |
| 라이선스 | MPL-2.0 | MIT | MIT (자체 코드) |
| 한글 초성 슬래시 검색 | 없음 | 직접 구현 | 구현됨 |
| 버블 툴바·표·이미지 업로드·ko UI·다크 모드 | 있음/부분 | 직접 구현 | 구현됨 |
| 번들(스파이크 기준) | 276kB | 224kB | 약 100kB |

## 결정
`oh-new-editor/packages/core`(커밋 `65acc2e`)를 `packages/editor`(`@nopsidian/editor`)로 복사해 포크한다.
소스를 그대로 가리키는 워크스페이스 패키지이며 빌드 단계는 없다.

## 이유
- 필요한 UI(슬래시, 버블 툴바, 표, 이미지)가 이미 있고, 특히 한글 초성 검색이 있다.
- ProseMirror 위의 작은 코드베이스라 우리 노드·슬래시 항목·블록 핸들을 직접 넣기 쉽다.
- 마크다운 직렬화는 어차피 우리 파서(1단계) 기반으로 새로 만든다.

## 결과 / 후속
- 업스트림은 아직 npm에 없다. 배포되면 변경분을 업스트림에 반영하고 `@oh-new-editor/core` 의존성으로 교체한다.
  (`packages/editor/UPSTREAM.md` 참고)
- 업스트림의 HTML 중심 마크다운 경로(`marked`/`turndown`)는 사용하지 않는다. 새 변환기가 완성되면 제거한다.
- 업스트림에 없는 것: 뷰 접근 API, 슬래시 항목 확장점, 블록 핸들·드래그, "Turn into", 소스 모드, 볼트 첨부 연동.
- 한글 IME 조합과 대용량 문서 성능은 구현 중 Playwright로 검증한다.
- 포크 코드는 업스트림과 diff를 유지하기 위해 lint 대상에서 제외하고, 고친 파일부터 점진적으로 포함한다.
